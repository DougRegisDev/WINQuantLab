# ADR-001

## Título

Separação das responsabilidades do módulo Data.

---

## Contexto

O sistema precisará importar dados de diferentes plataformas:

- Profit
- MetaTrader
- Binance
- B3
- Interactive Brokers

Cada plataforma pode utilizar nomes de colunas diferentes.

---

## Decisão

O Loader será responsável apenas pelo carregamento dos dados.

A validação ficará em um módulo separado.

A normalização ficará em outro módulo.

---

## Consequências

Vantagens:

- Código desacoplado.
- Fácil manutenção.
- Fácil expansão.
- Fácil criação de testes.

Desvantagens:

- Maior quantidade de arquivos.
- Arquitetura inicialmente mais complexa.

---

Status:

Aceita.
